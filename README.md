# Portfolio de Jorge López Calzado

Portfolio profesional estático creado con HTML, CSS y JavaScript, listo para
publicar en GitHub Pages sin compilación ni dependencias.

## Contenido

La página resume la experiencia, formación, herramientas e información de
contacto de Jorge López Calzado. La sección de casos destacados presenta
contribuciones profesionales descritas en el CV; no incluye datos internos ni
enlaces a materiales corporativos privados.

## Publicar con GitHub Pages

1. Sube estos archivos a la rama principal del repositorio.
2. Abre **Settings → Pages** en GitHub.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama principal y la carpeta **/(root)**; guarda los cambios.
5. Espera a que termine la publicación. GitHub mostrará la dirección del sitio
   en esa misma página de configuración.

Los archivos están directamente en la raíz, así que no hace falta un proceso de
build ni una configuración adicional. Los cambios que subas a la rama
seleccionada se publicarán automáticamente.
